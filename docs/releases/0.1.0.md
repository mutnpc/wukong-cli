# Wukong Code 0.1.0

The stable [v0.1.0 release](https://github.com/mutnpc/wukong-code/releases/tag/v0.1.0)
stabilizes one controllable, recoverable, and explainable Trusted Local Loop.
Wukong Code remains Free, local-first, and BYOK.

## Highlights

- Edit and approve one Preflight containing the Goal, Finish Line, exact checks
  or versioned no-check decision, provider destination, permissions, dirty
  workspace, iteration limit, provider-call ceilings, and optional token budget.
- Require complete, fresh evidence for `PASS`; incomplete, stale, conflicting,
  interrupted, or corrupt evidence fails closed.
- Separate `PASS`, `NEEDS_WORK`, and `ERROR` from `PAUSED` and
  `STOPPED_BY_USER`, with decisive evidence, file attribution, checks, usage,
  blocker, recovery, and next action.
- Upgrade directly from `v0.0.22` while preserving configuration and compatible
  local state.
- Import Codex, Claude Code, Cursor, Kimi Code, and Grok sessions as read-only
  context without importing trust or authorization.

## Install

macOS and Linux:

```sh
curl -fsSL https://wukong.today/install.sh | sh
wukong --version
```

Windows users should download the matching x64 or ARM64 ZIP and adjacent
SHA-256 file from the release page.

The macOS binaries are deliberately unsigned and unnotarized. The canonical
installer verifies SHA-256 and stops before replacement on mismatch. Release
provenance and immutable assets bind the six archives to the exact source and
catalog identity; no macOS app package is distributed.

Real-repository/source flows, first-user comprehension, and the opt-in cohort
continue after release as product-learning evidence. They are not represented
as completed and do not impose a fixed 14-day wait on the binary.
