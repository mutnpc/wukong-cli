# Wukong Code 0.1.1

The stable [v0.1.1 release](https://github.com/mutnpc/wukong-code/releases/tag/v0.1.1)
is a focused reliability and trust-boundary update for the local BYOK Loop.

## Reliability

- Loop revisions preserve the existing Finish Line and limits unless the user
  explicitly changes them.
- Resumed usage is scoped to the new run, provider imports are atomic, and an
  external session from another workspace is never imported into the current
  project by mistake.
- Local Web reconnects, permission controls, keyboard navigation, workspace
  persistence, dialogs, and side chats are more reliable.

## Trust boundaries

- Automatic updates are notification-only until the user explicitly runs
  `wukong upgrade`; invalid or incomplete configuration fails closed.
- Plugin downloads require HTTPS, enforce download and extraction limits,
  support SHA-256 verification, install disabled first, and roll back on failure.
- Project checks are discovered only from real root or workspace-member
  declarations, with the selected source retained as explainable provenance.

## Product boundary

Wukong Code 0.1.1 remains free, local-first, and bring-your-own-key. It adds no
top-level command, paid plan, hosted inference, managed model credits, or
expanded Gate semantics.

Stable release integrity is backed by six platform archives, adjacent SHA-256
files, exact-source provenance, pinned installation, direct upgrade from
v0.1.0, state recovery, and exact Website and Docs release markers.
